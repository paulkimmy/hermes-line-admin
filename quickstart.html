0เตรียมของ 3 อย่าง

  • บัญชี LINE OA ของธุรกิจ (มีอยู่แล้ว ใช้ได้เลย ไม่ต้องสร้างใหม่)
  • เครื่องรัน 24 ชม. — เลือก 1 ทาง: 💻 Mac ที่ไม่ปิดฝา / ☁️ Hostinger VPS (แนะนำ) template "Hermes Agent" ~200 บ./เดือน เปิดทั้งวันทั้งคืน
  • AI key หนึ่งตัว (OpenAI / Claude / Alibaba plan ฯลฯ) — Hermes ใช้เป็นสมอง ตอนรันสคริปต์จะมีจุดให้ใส่ key ให้อยู่แล้ว
ทำไมแนะนำ VPS? เพราะ "แอดมิน 24 ชม." ต้องไม่ตายตอนปิดเครื่อง — Mac เหมาะกับช่วงทดลอง (และเราแถม tunnel ชั่วคราวให้ในสคริปต์ mode mac อยู่แล้ว)

1สร้าง "ประตูบอท" ใน LINE Console

เข้า developers.line.biz/console → Login ด้วยบัญชี LINE ปกติ

1.1 สร้าง Provider (ถ้ายังไม่มี)

Messaging API tab → Create a Provider → ตั้งชื่ออะไรก็ได้ เช่น "My Business"

1.2 สร้าง Channel แบบ Messaging API

Create a Messaging API channel → กรอกชื่อธุรกิจ/รายละเอียด/หมวดหมู่ → Create.
ถ้ามันถามเชื่อมกับ LINE OA ที่มีอยู่แล้ว: ใช้หน้า LINE Official Account Manager → Add LINE Official Account from LINE Official Account Manager (เลือก OA ของคุณ)

1.3 ปิด Auto-reply + เลิกคุยเองก่อน

ใน Channel → tab Messaging API → Auto-reply messages = OFF, Greeting messages = OFF
ใน OA Manager → ตอบกลับอัตโนมัติ = ปิด ไม่งั้นบอทกับคุณตีกันเอง

2หยิบ Key 2 ตัว (เดี๋ยวต้องใช้ใส่สคริปต์)

2.1 Channel access token

tab Messaging API → ปุ่ม Issue (ใต้ "Channel access token (long-lived)") → กด Issue แล้ว copy ทั้งเส้นยาวๆ (ปกติยาว ~170 ตัว จบด้วย = — มันยาวของมันเองแบบนี้ ไม่ได้วางซ้ำ)

2.2 Channel secret

ใต้ "Channel secret" → copy ไว้ — เก็บสองอย่างดี ๆ ห้ามให้ใคร เพราะคือกุญแจบอท

3รันสคริปต์บนเครื่องของคุณ

Recommended
☁️ Hostinger VPSทำงานทั้งคืน

ซื้อ VPS template Hermes Agent → เปิด DNS โดเมนคุณชี้มา VPS (A record) → Browser Terminal ใน hPanel แล้วรัน:

curl -sL https://raw.githubusercontent.com/paulkimmy/hermes-line-admin/main/line-connect.sh -o line-connect.sh
bash line-connect.sh vps cloud.โดเมนคุณ.com

แล้ว วาง token + secret ตามที่ถาม จบ — สคริปต์สร้าง profile แยก ตรวจ token จัด Traefik HTTPS cert ให้เอง

ทดลองก่อน
💻 Mac เครื่องคุณ

ติดตั้ง Hermes แล้วเปิด Terminal รัน:

brew install cloudflared
curl -sL https://raw.githubusercontent.com/paulkimmy/hermes-line-admin/main/line-connect.sh -o line-connect.sh
bash line-connect.sh mac

สคริปต์จะเปิด tunnel ให้เอง + พิมพ์ URL สาธารณะ มาให้ (URL ชั่วคราว = ลองได้จริง แต่อย่าใช้กับลูกค้าถาวร และอย่าปิด Terminal)

❓ โหลดแล้วเก็บไว้ไหน?

ไว้ตรงไหนก็ได้ทั้งนั้น — สคริปต์รันจากโฟลเดอร์ที่คุณยืนอยู่ ไม่ต้องย้ายเข้าระบบไหน วิธีคือเปิด Terminal (Mac) หรือ Browser Terminal ใน hPanel (VPS) แล้ววาง 2 บรรทัดข้างบน มันดาวน์โหลด+รัน ณ ตำแหน่งนั้นเลย

ระหว่างทางสคริปต์เตือนอะไร = ทำตามที่มันบอก — ทุก pitfall ที่ทีมเราเคยเจอถูกฝังเป็น check ไว้แล้ว: token ผิด, profile ชนกัน, gateway บูตช้า ฯลฯ

4เอา URL ที่สคริปต์พิมพ์ให้ ไปวางใน Console

สคริปต์จะขึ้นบรรทัดสุดท้ายประมาณ:
https://cloud.โดเมนคุณ.com/p/adminbot/line/webhook
Copy → กลับไป LINE Console → Messaging API → ช่อง Webhook URL → วาง → Save
→ กด Verify (ต้องขึ้น 🟢) → เปิด Use webhook = ON

Verify ไม่ผ่าน? อย่าเพิ่งเดา — คัด URL ที่ "สคริปต์พิมพ์ให้ล่าสุด" เท่านั้น (สคริปต์คำนวณ path ถูกตามแบบเครื่องคุณทุกกรณี: ทั้งสองทางลงท้าย /p/adminbot/line/webhook เหมือนกัน ต่างแค่โดเมน)

5ทักหาบอทจากมือถือคุณ 🎉

  • เปิด LINE → ทัก OA ธุรกิจคุณ → พิมพ์ /new (เห็น Model ที่ AI ตั้งไว้ = สมองพร้อมแล้ว)
  • พิมพ์ hello — ถ้าบอทตอบกลับภายในไม่กี่วิ: คุณมีแอดมิน 24 ชม.แล้ว
  • ขั้นถัดไป (สำคัญ): สอนสมองบอท — ใส่ข้อมูลจริงของธุรกิจ เช่น "ค่าห้อง/สินค้า/เวลาเปิด/คำถามที่พบบ่อย" ให้ตอบรู้เรื่อง ไม่ใช่แค่ตอบเก่ง (อ่านต่อในไกด์หลัก เฟส 5)

6 Troubleshooting ที่เจอจริง 90% จบที่นี่

Webhook ได้ 502 Bad Gateway / Verify ไม่ผ่าน
แปลว่า "URL ถึงแล้ว แต่ข้างหลังยังไม่มีใครฟัง" → รัน line-connect.sh ซ้ำ หรือรอ gateway บูตให้จบ (~30 วิ) แล้ว Verify ใหม่
เปิดหน้า webhook แล้วขึ้น "Unknown or unconfigured profile"
ใจร้อนไป — gateway หลัง restart ใช้เวลา ~30 วิ กว่าจะรับงาน — รอครบแล้วลองใหม่ ผ่านแน่นอน
บอทตอบว่า Rate limited (429)
AI key หมดโควตา — ไม่ใช่ระบบพัง: พิมพ์ /model เพื่อสลับตัวที่โควตายังเหลือ หรือเติม credit ของผู้ให้บริการนั้น
ทักแล้วเงียบสนิท (ไม่มีข้อความจาก HelloOA)
ตรวจ 3 จุด: ① Use webhook ON? ② Verify 🟢? ③ ปิด "ตอบกลับอัตโนมัติ" ใน OA Manager หรือยัง? — ครบสามแล้วทักใหม่ ถ้าเงียบอยู่ เปิด log ของ gateway ดูบรรทัด line connected ว่ามีไหม
LINE ตอบซ้ำ 2 รอบ / เดี๋ยวตอบเดี๋ยวไม่ตอบ
บอท 2 ตัวแย่ง OA เดียวกัน (profile ซ้ำ token เดียวกัน) — สคริปต์กันไว้ให้แล้ว ถ้าไปเปิดเพิ่มเอง: OA หนึ่งตัวต้องอยู่กับ profile เดียวเท่านั้น
ปลอดภัยไว้ก่อน — บอทที่ต่อ LINE สาธารณะ = ใครก็พิมพ์สั่งมันได้ สคริปต์ปลดอาวุธบอทให้ตั้งแต่แรก (ห้ามเข้าถึงไฟล์/สั่งเครื่อง) อย่าเปิดให้เอง และข้อมูลลูกค้า = PDPA เก็บ KB ในเครื่องตัวเองพอ
